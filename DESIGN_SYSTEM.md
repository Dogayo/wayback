# Wayback — дизайн-система (v0.2)

> Справочник токенов и компонентов для генерации UI. Живой интерактивный плейграунд (свотчи, состояния, сравнение iOS/Android): https://claude.ai/code/artifact/09d490da-bdcd-4b1c-8d18-952afbe307c0
>
> Источники: `README.md`, `docs/mvp-scope.md`, `docs/architecture.md`. На момент создания в репозитории не было `BRAND.md` / `SCREENS.md` — палитра, типографика и компоненты ниже являются **новым решением** («Точность и инструментальность»), а не переносом существующего бренда.
>
> При генерации любого экрана или виджета: используй только токены и компоненты из этого файла. Если чего-то не хватает — сначала расширь этот файл (новый вариант компонента, новый паттерн), потом используй на экране. Никаких произвольных hex/px значений в коде экранов.

## Принципы

1. **Читаемо при дневном свете** — контраст и размер в приоритете, приложение используется на улице, часто на солнце.
2. **Честность в отношении погрешности** — точность GPS/компаса показывается, не скрывается.
3. **Один взгляд — одно решение** — экран навигации отвечает на два вопроса: куда и сколько осталось.
4. **Тихо, пока не важно** — цвет/движение/haptics только для значимых изменений состояния.
5. **Одна система, две платформы** — бренд общий, механика взаимодействия адаптируется под iOS/Android.
6. **У каждого значения есть имя** — нет токена → нет права использовать значение в коде.

## Отступы (сетка 4pt)

`spacing2xs`=4 · `spacingXs`=8 · `spacingSm`=12 · `spacingMd`=16 (базовый, отступ экрана по умолчанию) · `spacingLg`=20 · `spacingXl`=24 · `spacing2xl`=32 · `spacing3xl`=40 · `spacing4xl`=48.

## Форма и высота

- Радиусы: `radiusSm`=8 (чипы, бейджи) · `radiusMd`=12 (кнопки, поля, элементы списка) · `radiusLg`=20 (карточки, диалоги, шторки) · `radiusFull`=999 (аватары, switch, FAB).
- Границы: `borderThin`=1dp (по умолчанию) · `borderThick`=2dp (фокус, выбор).
- Elevation: L0 без тени (фон) → L1 только заливка (контейнеры) → L2 `shadow1` (карточки) → L3 `shadow2` (snackbar, поповер) → L4 `shadow3` + `scrim` (диалог, шторка). Тень — вторична; иерархия держится в первую очередь на заливке/границе (плохая видимость теней на солнце).

## Движение

Токены — `WbMotion`, макеты — Penpot «01 · Foundations → Движение» и «05 · Motion». Длительности: `instant`=100 (нажатие, цвет мелких элементов) · `fast`=150 (цвет выбора, текст ↔ спиннер в кнопке) · `base`=220 (смена состояния в блоке, изменение высоты, бегунок вкладок) · `slow`=320 (открытие экрана, прибытие) · `slowExit`=250 (закрытие экрана) · `compassSmoothing`=120 · `shimmer`=1400 · `undoWindow`=5000. Кривые: появление — `easeOut`, исчезновение — `accelerate`, движение внутри экрана — `standard`, iOS — `ios`. Без bounce и spring.

- Длительность в компоненте — всегда `WbMotion.of(context, …)`: при системном «Убрать анимации» она нулевая.
- Переходы экранов — `WbPage(transition:)`: `drill` (сдвиг 30dp + растворение; Главный → Настройки, Все точки, Детали, Вибрация), `modal` (снизу вверх поверх экрана, нижний затемняется ~8%; Создание точки), `enterMode` (масштаб 0,92 → 1 + растворение; вход в навигацию), `fade` (старый исчезает, потом появляется новый; Онбординг → Главный). Входящий экран сам решает, что делает экран под ним; экран под ним растворяется в `surfaceDefault`, а не в чёрный. На iOS `drill` и `enterMode` — системный Cupertino со свайпом назад.
- Смена состояний — `WbStateSwitcher(state:)`: растворение по смене вида состояния (загрузка / данные / пусто / ошибка), а не по новым данным; `animateSize` — для блоков, которые меняют высоту; `fadeThroughStart` и `scaleFrom` — для прибытия.
- Шторка действий: `slow` / `slowExit`. Свайп идёт за пальцем, после отпускания защёлкивается за `base`, `standard`. Кольцо снекбара — `undoWindow`, `linear`.
- Цифры расстояния, точность и стрелку не анимируем дополнительно — «тихо, пока не важно».

## Отклик

Вибрация только на смену состояния и результат: кнопки, «назад», переходы и прокрутка молчат. Обновления GPS и компаса тоже: телефон может быть в кармане. Прибытие — отдельная настройка и свой рисунок, не входит в эти уровни.

| Уровень | Импульс, мс | Для чего |
|---|---|---|
| `tick` | 30 | выбор: что-то переключилось |
| `press` | 40 | сработал особый жест, что-то открылось |
| `success` | 40 · 60 · 40 | важное действие завершено |
| `warning` | 70 · 60 · 70 | отказ или ошибка |

| Событие | Уровень |
|---|---|
| Долгое нажатие открыло шторку | `press` |
| Свайп защёлкнул панель действий | `tick` |
| Вкладки, иконка типа, радио, переключатель | `tick` |
| Пункт шторки, шторка «+» | — (отклик даёт результат) |
| Точка сохранена | `success` |
| Точка переименована, сделана активной или неактивной | `tick` |
| Удаление подтверждено | `press` |
| «Вернуть» в снекбаре | `tick` |
| Отсчёт снекбара закончился | — |
| Пустое название, нераспознанные координаты | `warning` |
| Ошибка сохранения, удаления, отправки | `warning` |
| «Скопировать координаты» | `tick` |
| Обычные кнопки, «назад», переходы, прокрутка | — |
| Обновления GPS и компаса, потеря сигнала | — |

- Android: импульс напрямую на вибромотор, потому что системный отклик молчит при выключенной «вибрации при касании» (так было на Samsung M32 и Redmi). iOS: `HapticFeedback`.
- Результат действия слушается только через `ActionResultListener`: он сам вибрирует при успехе и ошибке и показывает текст ошибки. Обычный `BlocListener` на `ActionState` запрещён тестом архитектуры.
- Настройка «Отклик при нажатиях» включена по умолчанию и не зависит от «Вибрации при прибытии».
- Не чаще одного импульса в 50 мс. Длительности подбираются на реальных телефонах: вибромоторы сильно различаются.

## Иконография

Material Icons (`Icons.*`), контурные варианты — единый набор на обеих платформах. Размеры: `iconSm`=16dp (в тексте) · `iconMd`=20dp/44dp-таргет · `iconLg`=24dp/44dp-таргет · `iconXl`=32dp/48dp-таргет (глифы типа точки) · `icon2xl`=48dp (пустые состояния). Визуальный размер иконки ≠ область нажатия — таргет всегда ≥44×44dp.

## Доступность

Контраст 4.5:1 (текст) / 3:1 (крупный текст, функциональные границы) · область нажатия ≥44×44dp всегда · состояние никогда не только цветом (иконка/текст обязательны) · масштабирование текста до 200% без обрезки (`MediaQuery.textScaler`, гибкие размеры контейнеров) · видимое состояние фокуса (кольцо 2dp) · `Semantics`-метки на иконочных элементах, live-region для непрерывно обновляющихся значений (расстояние/азимут) — троттлинг озвучивания ещё не спроектирован (открытый риск).

## Компоненты

**Кнопки** (`WbButton(variant, size, icon?, loading, enabled, onPressed)`): `primary` (заливка `actionPrimaryBg`) · `secondary` (контур `borderDefault`) · `tertiary` (текст `brand600`, без фона/границы) · `destructive` (контур `negative`, заливка только в диалоге подтверждения). Размеры: `medium` (44dp), `small` (36dp, плотные контексты). Состояния: default / pressed (тональный сдвиг) / focused (кольцо) / disabled (60% прозрачности) / loading (спиннер растворяется поверх подписи, ширина кнопки не меняется).

**Поля ввода**: `WbAnimatedPointIcon(type, active:, playOnAppear:)` — иконка типа точки со своим коротким движением (320 мс, один раз; при «Убрать анимации» сразу на месте), её использует `WbTypePicker` · `WbTextField(maxLength:)` и `WbDialogs.prompt(validator:, maxLength:)` — ввод останавливается на лимите, счётчик появляется с 75% лимита; ошибка `validator` показывается при подтверждении, держит диалог открытым и снимается при вводе · `WbTextField`, `Checkbox`, `Radio`, `Switch` (платформо-адаптивный), пикер типа точки (`WbTypePicker`) — сетка иконок 4×2, а не dropdown; выбранная плитка залита `actionPrimaryBg` с текстом `actionPrimaryFg`, а не `brand600`: в тёмной теме `brand600` слишком светлый для белой подписи (2,6:1). Состояния текстового поля: empty / focused / filled / error (красная граница + сообщение) / disabled / с ведущей иконкой / с хвостовым действием / с helper-текстом.

**Контент**: `WbQrCode(data)` — QR всегда чёрный на белом, с полем вокруг, и в тёмной теме; до 285dp · `WbSwipeActions` — свайп к началу строки открывает кнопки 88dp, открыта одна строка, само действие свайпом не выполняется; скринридеру те же действия дают другим путём · `WbAnimatedItems` — короткий список из потока: сам находит ушедшие и новые строки, сворачивает и разворачивает их (`base`) · `WbListItem` (ведущая иконка · заголовок · подзаголовок · хвостовой элемент, min-height 64dp, есть `selected`-состояние для активной точки; в списке точек ведущий элемент — `WbIconTile(compact: true)`, круг 40dp, а бейдж «Скрыта» стоит перед шевроном только у точек не на главной: таких меньше, поэтому метка достаётся им), `WbPointCard` (активная точка на главном: круг со стрелкой-направлением · имя с иконкой типа · расстояние `headlineSmall` · шеврон; круг заполняет `direction`, обычно `WbPointDirection`: стрелка `brand600` и при неточном компасе, без направления иконка типа) и `WbPointCardSkeleton` той же высоты для загрузки, `WbPointHeroCard` (единственная точка на главном: полный диск `dialSize` 240dp, имя, расстояние `WbDistanceValue(compact: true)`), `Card`, `Avatar` (заглушка — первая буква, фото нет в MVP), `Badge`, `Chip` (с `selected`-состоянием), `Divider`.

**Навигация**: верхний `WbAppBar` с адаптивной кнопкой «назад» (`WbBackButton`), заголовок сразу за её слотом 56dp, нижняя навигация специфицирована, но не используется в MVP (всего 4 маршрута), вкладки/сегментированный переключатель `WbSegmentedTabs`: равные сегменты в плашке `segmentTrack` высотой 44 со скруглением `md`, выбранный — плашка `segmentSelected` 36 со скруглением `sm`, которая скользит к новому выбору (`base`, `standard`), текст `labelMedium` 500 `contentPrimary`; тап принимает вся высота сегмента, при крупном шрифте подписи переносятся. В тёмной теме плашка светлее выбранного, поэтому у переключателя свои токены. `WbPageDots` — позиция в короткой последовательности экранов (онбординг): текущий шаг — пилюля 24×8 `brand600`, остальные — точки 8×8 `borderSubtle`, для скринридера — подпись «Шаг N из M».

**Направление** (`wayfinding/wb_direction_dial.dart`): `WbDirectionDial(rotation, spread, semanticLabel)` — диск `surfaceContainer` с кольцом `borderDefault`, неподвижной меткой `contentPrimary` на 12 часов (куда смотрит телефон), гранёной стрелкой (`brand500` + `actionPrimaryBg`, как грани знака приложения; нос длиннее хвоста) и лучом погрешности: `spread` — полуширина луча в градусах, 10–45, ширина и есть честный показ точности компаса. При неточном компасе стрелка остаётся брендовой: о неточности говорят широкий луч и янтарная плашка над диском, цветом выделяется только она. `WbDirectionSearching` — тот же диск с дугой, бегущей по краю, пока направления нет. `WbDirectionIcon(icon)` — диск с иконкой, когда направления не будет. `WbDirectionFinding` — диск сам находит направление за 1,6 с, иллюстрация без датчиков. `WbDirectionArrow` — маленькая одноцветная стрелка. `WbDistanceValue` — расстояние: число `displayLarge`, единица `displaySmall`, `color` — для цветного поля. `WbArrivalDial(type, rotation)` — прибытие: иконка типа точки в диске и указатель на кольце, пока известно направление; появляется один раз за 480 мс (диск раскрывается пружиной, иконка играет своё движение, указатель выходит на кольцо), при «Убрать анимации» сразу на месте. `context.wbArrivalColors` — полноэкранное прибытие: насыщенный `positive` в светлой теме, приглушённый `positiveBg` в тёмной, чтобы не слепить ночью. `WbAppBar(onField:)` — бар поверх такого поля.

**Иллюстрации**: `WbIllustration(kind)` — декоративная картинка в круге `surfaceContainer` для поясняющих экранов: `compassRose` (знак приложения), `trail` (точка, пунктир пути и стрелка назад), `location` (текущее местоположение с кольцами). Цвета — `brand500`/`brand600`/`contentDisabled`, скрыта от скринридера: смысл несёт текст рядом. Макеты — Penpot «03 · Screens», Onboarding / Step 1–3.

**Обратная связь**: `WbBottomSheet.show` — шторка с формой, поднимается с клавиатурой · `WbSnackbar.show(actionLabel:)` — не больше одной кнопки, исчезает сама · `WbActionSheet.show` — действия над одним объектом шторкой снизу на обеих платформах (иконка и заголовок, строки 56dp, деструктивная красным) · `WbUndoSnackbar.show` — снекбар с кольцом и секундами (`undoWindow`=5с) и кнопкой отмены; в фоне отсчёт стоит, со скринридером отсчёта нет · `WbDialogs.confirm(...)` (платформо-адаптивный: `CupertinoAlertDialog` / Material `AlertDialog`; при `destructive` действие красное, «Отмена» нейтральная), `BottomSheet` (грабер + скруглённые верхние углы, общая форма на обеих платформах), `Snackbar`, встроенный `Alert` (warning/negative/positive, всегда иконка + текст), однострочный `WbAlertRow` («заголовок: текст») для экранов, которые читают на ходу: `WbAlertRow.slotHeight` резервирует место под две строки, чтобы контент ниже не прыгал, `ProgressIndicator` (определённый/неопределённый), `Skeleton`.

Полная матрица состояний (компонент × default/pressed/focused/disabled/loading/error/selected) — в интерактивном плейграунде, раздел «Матрица состояний».

## Паттерны

Запрос разрешения (диалог, платформо-специфичный) · сценарий сохранения точки (Primary-кнопка → Snackbar/карточка подтверждения → опциональное переименование, ≤1 тап) · деструктивное подтверждение (всегда с названным последствием, никогда голое «Вы уверены?») · пустое состояние (иконка + заголовок + текст + Primary-кнопка) · состояние ошибки (Alert negative + текст по `failure.code`) · состояние загрузки (Skeleton для списков, ProgressIndicator + подпись для единичных значений) · секция настроек (заголовок + сгруппированные `ListItem`).

## Адаптация iOS / Android

Бренд не меняется между платформами; механика — да. Ключевые различия: диалоги (центр/без иконки, кнопки в ряд ↔ заголовок слева, текстовые кнопки справа-снизу), шторки (общая форма, разная кривая анимации), Switch (`CupertinoSwitch`/`Switch`, перекрашены в бренд), навигация назад (edge-swipe ↔ системный жест/кнопка), системные панели (экран идёт под них, панели прозрачные; `WbSystemBars(background:)` подбирает цвет значков, прокрутка заканчивается с `context.wbScrollPadding`), отклик (см. раздел «Отклик»). Полная таблица с обоснованием — в разделе «Адаптация iOS / Android» плейграунда.

## Маппинг во Flutter

- `ThemeExtension<WaybackColors>` → `app/theme/wayback_colors.dart` (семантические цвета, `light`/`dark`).
- `TextTheme` → `app/theme/wayback_text_theme.dart` (шкала выше, `fontFamily` не задан — платформенный дефолт).
- `ThemeExtension<WaybackTokens>` или `static const` → `app/theme/wayback_tokens.dart` (spacing/radius/elevation — не зависят от темы).
- `ColorScheme` в `app/theme/app_theme.dart` заполняется явно из семантических токенов (без `ColorScheme.fromSeed`), чтобы сторонние Material-виджеты наследовали бренд.
- Компоненты — виджеты в `packages/wayback_design_system`, читают токены через `context.wbColors` / `Theme.of(context).textTheme`, платформенное ветвление (`Theme.of(context).platform`) спрятано внутри компонента, а не в вызывающем экране.
- Соответствует `docs/architecture.md`: `core` не импортирует `features`, поэтому все компоненты доступны любому экрану без нарушения правила зависимостей.
