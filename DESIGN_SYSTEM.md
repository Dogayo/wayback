# Wayback — дизайн-система (v0.1)

> Справочник токенов и компонентов для генерации UI. Живой интерактивный плейграунд (свотчи, состояния, сравнение iOS/Android): https://claude.ai/code/artifact/09d490da-bdcd-4b1c-8d18-952afbe307c0
>
> Источники: `README.md`, `docs/mvp-scope.md`, `docs/architecture.md`. На момент создания в репозитории не было `BRAND.md` / `SCREENS.md` — палитра, типографика и компоненты ниже являются **новым решением** («Точность и инструментальность»), а не переносом существующего бренда.
>
> При генерации любого экрана или виджета: используй только токены и компоненты из этого файла. Если чего-то не хватает — сначала расширь этот файл (новый вариант компонента, новый паттерн), потом используй на экране. Никаких произвольных hex/px значений в коде экранов.

## Принципы

1. **Читаемо при дневном свете** — контраст и размер в приоритете, приложение используется на улице, часто на солнце.
2. **Честность в отношении погрешности** — точность GPS/компаса показывается, не скрывается.
3. **Один взгляд — одно решение** — экран навигации отвечает на два вопроса: куда и сколько осталось.
4. **Тихо, пока не важно** — цвет/движение/haptics только для значимых изменений состояния.
5. **Одна система, две платформы** — бренд общий, механика взаимодействия адаптируется под iOS/Android.
6. **У каждого значения есть имя** — нет токена → нет права использовать значение в коде.

## Отступы (сетка 4pt)

`spacing2xs`=4 · `spacingXs`=8 · `spacingSm`=12 · `spacingMd`=16 (базовый, отступ экрана по умолчанию) · `spacingLg`=20 · `spacingXl`=24 · `spacing2xl`=32 · `spacing3xl`=40 · `spacing4xl`=48.

## Форма и высота

- Радиусы: `radiusSm`=8 (чипы, бейджи) · `radiusMd`=12 (кнопки, поля, элементы списка) · `radiusLg`=20 (карточки, диалоги, шторки) · `radiusFull`=999 (аватары, switch, FAB).
- Границы: `borderThin`=1dp (по умолчанию) · `borderThick`=2dp (фокус, выбор).
- Elevation: L0 без тени (фон) → L1 только заливка (контейнеры) → L2 `shadow1` (карточки) → L3 `shadow2` (snackbar, поповер) → L4 `shadow3` + `scrim` (диалог, шторка). Тень — вторична; иерархия держится в первую очередь на заливке/границе (плохая видимость теней на солнце).

## Иконография

Material Symbols, Outlined, обводка 2dp — единый набор на обеих платформах. Размеры: `iconSm`=16dp (в тексте) · `iconMd`=20dp/44dp-таргет · `iconLg`=24dp/44dp-таргет · `iconXl`=32dp/48dp-таргет (глифы типа точки) · `icon2xl`=48dp (пустые состояния). Визуальный размер иконки ≠ область нажатия — таргет всегда ≥44×44dp.

## Доступность

Контраст 4.5:1 (текст) / 3:1 (крупный текст, функциональные границы) · область нажатия ≥44×44dp всегда · состояние никогда не только цветом (иконка/текст обязательны) · масштабирование текста до 200% без обрезки (`MediaQuery.textScaler`, гибкие размеры контейнеров) · видимое состояние фокуса (кольцо 2dp) · `Semantics`-метки на иконочных элементах, live-region для непрерывно обновляющихся значений (расстояние/азимут) — троттлинг озвучивания ещё не спроектирован (открытый риск).

## Компоненты

**Кнопки** (`AppButton(variant, size, icon?, loading, enabled, onPressed)`): `primary` (заливка `actionPrimaryBg`) · `secondary` (контур `borderDefault`) · `tertiary` (текст `brand600`, без фона/границы) · `destructive` (контур `negative`, заливка только в диалоге подтверждения). Размеры: `medium` (44dp), `small` (36dp, плотные контексты). Состояния: default / pressed (тональный сдвиг) / focused (кольцо) / disabled (60% прозрачности) / loading (спиннер вместо подписи).

**Поля ввода**: `AppTextField` (+ password/search-варианты), `AppTextArea`, `Checkbox`, `Radio`, `Switch` (платформо-адаптивный), пикер типа точки (`WbTypePicker`) — сетка иконок 4×2, а не dropdown; выбранная плитка залита `actionPrimaryBg` с текстом `actionPrimaryFg`, а не `brand600`: в тёмной теме `brand600` слишком светлый для белой подписи (2,6:1). Состояния текстового поля: empty / focused / filled / error (красная граница + сообщение) / disabled / с ведущей иконкой / с хвостовым действием / с helper-текстом.

**Контент**: `AppListItem` (ведущая иконка · заголовок · подзаголовок · хвостовой элемент, min-height 64dp, есть `selected`-состояние для активной точки), `WbPointCard` (активная точка на главном: круг со стрелкой-направлением · имя с иконкой типа · расстояние `headlineSmall` · шеврон; без `rotation` стрелка скрыта) и `WbPointCardSkeleton` той же высоты для загрузки, `Card`, `Avatar` (заглушка — первая буква, фото нет в MVP), `Badge`, `Chip` (с `selected`-состоянием), `Divider`.

**Навигация**: верхний `AppBar` с адаптивной кнопкой «назад» (`AppBackButton`), нижняя навигация специфицирована, но не используется в MVP (всего 4 маршрута), вкладки/сегментированный переключатель. `WbPageDots` — позиция в короткой последовательности экранов (онбординг): текущий шаг — пилюля 24×8 `brand600`, остальные — точки 8×8 `borderSubtle`, для скринридера — подпись «Шаг N из M».

**Направление** (`wayfinding/wb_direction_dial.dart`): `WbDirectionDial(rotation, spread, tone, semanticLabel)` — диск `surfaceContainer` с гранёной стрелкой (`brand500` + `actionPrimaryBg`, как грани знака приложения) и лучом погрешности: `spread` — полуширина луча в градусах, 10–45, ширина и есть честный показ точности компаса; `tone: unreliable` красит стрелку и луч в янтарный. `WbDirectionSearching` — тот же диск с дугой, бегущей по краю, пока направления нет. `WbDirectionIcon(icon)` — диск с иконкой, когда направления не будет. `WbDirectionArrow` — маленькая одноцветная стрелка. `WbDistanceValue` — расстояние: число `displayLarge`, единица `displaySmall`. `WbArrivalMark` и `context.wbArrivalColors` — полноэкранное прибытие: насыщенный `positive` в светлой теме, приглушённый `positiveBg` в тёмной, чтобы не слепить ночью. `WbAppBar(onField:)` — бар поверх такого поля.

**Иллюстрации**: `WbIllustration(kind)` — декоративная картинка в круге `surfaceContainer` для поясняющих экранов: `compassRose` (знак приложения), `trail` (точка, пунктир пути и стрелка назад), `location` (текущее местоположение с кольцами). Цвета — `brand500`/`brand600`/`contentDisabled`, скрыта от скринридера: смысл несёт текст рядом. Макеты — Penpot «03 · Screens», Onboarding / Step 1–3.

**Обратная связь**: `AppDialog.confirm(...)` (платформо-адаптивный: `CupertinoAlertDialog` / Material `AlertDialog`), `BottomSheet` (грабер + скруглённые верхние углы, общая форма на обеих платформах), `Snackbar`, встроенный `Alert` (warning/negative/positive, всегда иконка + текст), однострочный `WbAlertRow` («заголовок: текст») для экранов, которые читают на ходу: `WbAlertRow.slotHeight` резервирует место под две строки, чтобы контент ниже не прыгал, `ProgressIndicator` (определённый/неопределённый), `Skeleton`.

Полная матрица состояний (компонент × default/pressed/focused/disabled/loading/error/selected) — в интерактивном плейграунде, раздел «Матрица состояний».

## Паттерны

Запрос разрешения (диалог, платформо-специфичный) · сценарий сохранения точки (Primary-кнопка → Snackbar/карточка подтверждения → опциональное переименование, ≤1 тап) · деструктивное подтверждение (всегда с названным последствием, никогда голое «Вы уверены?») · пустое состояние (иконка + заголовок + текст + Primary-кнопка) · состояние ошибки (Alert negative + текст по `failure.code`) · состояние загрузки (Skeleton для списков, ProgressIndicator + подпись для единичных значений) · секция настроек (заголовок + сгруппированные `ListItem`).

## Адаптация iOS / Android

Бренд не меняется между платформами; механика — да. Ключевые различия: диалоги (центр/без иконки, кнопки в ряд ↔ заголовок слева, текстовые кнопки справа-снизу), шторки (общая форма, разная кривая анимации), Switch (`CupertinoSwitch`/`Switch`, перекрашены в бренд), навигация назад (edge-swipe ↔ системный жест/кнопка), контекстное меню (floating-меню ↔ bottom sheet), системные панели (`SystemUiOverlayStyle` явно на каждый экран под тему), haptics (`HapticFeedback.lightImpact()` при сохранении, `.mediumImpact()` один раз при входе в радиус прибытия — без повторов). Полная таблица с обоснованием — в разделе «Адаптация iOS / Android» плейграунда.

## Маппинг во Flutter

- `ThemeExtension<WaybackColors>` → `app/theme/wayback_colors.dart` (семантические цвета, `light`/`dark`).
- `TextTheme` → `app/theme/wayback_text_theme.dart` (шкала выше, `fontFamily` не задан — платформенный дефолт).
- `ThemeExtension<WaybackTokens>` или `static const` → `app/theme/wayback_tokens.dart` (spacing/radius/elevation — не зависят от темы).
- `ColorScheme` в `app/theme/app_theme.dart` заполняется явно из семантических токенов (без `ColorScheme.fromSeed`), чтобы сторонние Material-виджеты наследовали бренд.
- Компоненты — виджеты в `core/widgets/`, читают токены через `context.waybackColors` / `Theme.of(context).textTheme`, платформенное ветвление (`Theme.of(context).platform`) спрятано внутри компонента, а не в вызывающем экране.
- Соответствует `docs/architecture.md`: `core` не импортирует `features`, поэтому все компоненты доступны любому экрану без нарушения правила зависимостей.
